Documentation (SALBAG - Smart Anti-Theft Device)

Abstract

This paper presents the development of a Smart Anti-Theft Device (SALBAG) aimed at addressing the increasing crime cases in the Philippines. The device enhances security and provides substantial evidence in theft incidents through real-time GPS tracking, face detection, and panic alarm functionality, all managed via a mobile application.

The device uses a Raspberry Pi 4B, CMOS camera, and OpenCV library for face detection. Upon activation, it sends real-time updates and images to designated email addresses for evidence collection. The project aligns with Sustainable Development Goal 9: Industry, Innovation, and Infrastructure.

Problem Statement

The Philippines continues to face rampant cases of theft and kidnapping, with many crimes going unresolved due to lack of surveillance and poor evidence collection.

Key challenges include rising theft incidents nationwide, lack of effective monitoring systems, and inadequate quality evidence collection.

Project Objectives

1
Hardware Innovation

Develop an anti-theft bag equipped with real-time GPS module and image detection camera.

2
Mobile Application

Create an intuitive mobile app with navigation, real-time tracking, and email notifications.

3
Evidence Collection

Provide clear and substantial evidence to aid in theft and kidnapping investigations.

Technical Specifications

Hardware Components: Raspberry Pi 4B (central controller), GPS NEO8MV2 Module (real-time navigation), CMOS Camera Module (evidence collection), SanDisk Ultra 32GB MicroSD (data storage), Raspberry Pi 4B+ Case (protection), Active Buzzer & Button (panic alarm).

Software Environment
Development Platform
OS: Raspberry Pi OS
Language: Python
IDE: Thonny IDE 4.1.4
Key Libraries
OpenCV: Face detection & image processing
GPSD: GPS data parsing
SMTP: Email notifications

Scope and Limitations

Scope & Limitations: The project scope includes integration of Raspberry Pi 4B with GPS and camera modules, OpenCV face detection, mobile application development, and panic alarm system. Limitations include exclusion of additional sensors, GSM/WiFi modules, and reliance on external power sources.

Project Impact

Benefits the general public through enhanced safety and reduced anxiety, supports security sectors with improved crime prevention and evidence collection, and serves as a foundation for future IoT security innovations and scalable safety solutions.

Property Custodian Management System

The Property Custodian Management System is a sophisticated Institutional Resource Planning (IRP) solution designed to digitize the end-to-end lifecycle of institutional property. It serves as a centralized hub for managing both consumable and non-consumable assets—from procurement and QR-based registration to real-time tracking, preventive maintenance scheduling, and secure digital issuance.

Documentation (Smart Distancing Belt)

Abstract

This paper presents the development of an Arduino-based Modified Waist Belt with incorporated Passive Infrared and Ultrasonic sensors designed to maintain safe physical distancing during the COVID-19 pandemic. The device provides real-time motion detection, distance monitoring, and audio-visual alerts to help individuals maintain at least 1 meter of social distance.

The belt uses Arduino Nano microcontroller, PIR motion sensor, and ultrasonic distance sensor with LED and buzzer feedback systems. The project offers practical support for students, frontliners, and people with disabilities, contributing to reduced virus transmission in crowded areas.

Problem Statement

The COVID-19 pandemic highlighted the critical need for maintaining safe physical distances to prevent virus transmission. Many individuals, especially vulnerable populations, struggled to consistently maintain proper distancing protocols. This project addresses:

Distance Awareness
Difficulty maintaining 1-meter safe distance
Vulnerable Groups
PWDs and elderly need assistive technology
Compliance
Inconsistent adherence to distancing protocols

Project Objectives

1
Wearable Device Development

Design an Arduino-based wearable belt with PIR and ultrasonic sensors for distance monitoring.

2
Alert System Integration

Implement LED and buzzer alerts when social distancing protocols are breached.

3
Assistive Technology

Provide practical support for students, frontliners, and people with disabilities.

Technical Specifications

Hardware Components

The device utilizes Arduino Nano as the central microcontroller for sensor integration and logic processing, PIR Motion Sensor for detecting human movement and presence within sensor range, Ultrasonic Sensor for measuring distance to objects using ultrasonic waves, 3V Piezo Buzzer for audio alert system for distance breach notifications, Red LED for visual indicator for social distancing violations, Nylon Strap & Buckle for wearable belt structure with adjustable fitting, Plastic Enclosure Box for protection housing for electronic components, and Supporting Components including breadboard, jumper wires, resistors, battery holder, and 9V battery.

Device Assembly
Arduino Compartments inside Plastic Enclosure connected to Belt
Software Environment
Development Platform

Language: C/C++ (Arduino)
Simulation: Tinkercad
System Logic
Input: PIR sensor, Ultrasonic sensor
Output: LED indicator, Buzzer alarm
Trigger: Distance < 1m OR motion detected
